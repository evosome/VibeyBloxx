# ADR-002: Стандартные решения от Godot

- **Статус:** Принято
- **Дата:** 2026-10-14
- **Контекст:** Не стоит усложнять проект кастомной физикой и классами, насл. Object
- **Решение:** Использовать стандартные решения движка для физики и добавление/удаление узлов в SceneTree.
- **Последствия:** из плюсов мало кода, быстрое проектирование.

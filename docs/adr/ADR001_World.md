# ADR-001: Класс `World` выступает контейнером и посредником для игровых сущностей

- **Статус:** Принято
- **Дата:** 2026-10-14
- **Контекст:** Класс `World` выступает хранилищем для всех игровых сущностей (типа, башня, падающие блоки, кран и проч.). Некоторым сущностням необходима ссылка на игровой мир, где они находятся для особый логики.
- **Решение:**
1. класс `World` предоставляет методы добавления, удаления и получения актеров внутри мира.
2. Те акторы, которым нужна ссылка на мир, реализуют метод `spawn(world: World)`.
3. Если актор создается из префаба (сцены через `instantiate`), то он реализует статический метод `make(world, ...)`, который полностью инициализирует актора и задаст ссылку на мир:
```gdscript
static func make(world: World, ...) -> SomeActor:
    var instance = SOME_ACTOR_SCENE.instantiate()
    instance._world = world
    ...
```
- **Последствия:**
1. Двойная связность. Актор знает о мире, мир знает акторов.

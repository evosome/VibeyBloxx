# ADR-003: Структура папок

- **Статус:** Принято
- **Дата:** 2026-10-14
- **Контекст:** нужна адекватная структура папок для хранения ресурсов и скриптов игры.
- **Решение:** Использовать три директории: `assets`, `resources`, `scripts`, `scenes`, где:
1. `assets` - хранилище ассетов игры, подразделяется на:
    * `sounds`
    * `textures`
    * `fonts`,
2. `resources` - хранилище ресурсов игры в форматах `.tres`, `.json` и других,
3. `scripts` - хранилище кода и логики,
4. `scenes` - хранилище `.tscn` файлов.
- **Последствия:**
1. Ассеты, ресурсы и код четко разделены
2. Хорошей практикой считается нахождение скрипта и сцены в одной папке. Ранее были проблемы с указанием пути до сцены, сейчас решается через UID ресурса сцены.
